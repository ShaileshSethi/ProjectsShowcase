# Midnight Build Club

Halloween hackathon playground built with React/Vinext, GSAP, Three.js and Cloudflare D1.

Run: npm install, then npm run dev. Build: npm run build.
Project submissions are shared via D1; drafts and checklists are local to each browser. The Idea Lab uses a curated collection of nine project seeds, editable briefs and remix prompts; no external AI key is required. Students copy a prompt into their own Codex workspace and return with a published URL.

For local D1 setup, build first, then apply drizzle/0000_greedy_toro.sql with the Wrangler D1 execute command in the starter README. Production migrations are applied by Sites publication.

The site is initially published owner-private. Student access needs to be configured before the event. No student content is pre-seeded into production.

Art: public/workshop.png generated using the built-in image generation tool from the approved entrance reference.
